Run these commands in your repository root to commit changes and create a tag:

# Stage all changes
git add -A

# Commit
git commit -m "Bump to v1.1.10: add backup & restore (with preserve IDs option), improved restore error reporting, update changelog and tests"

# Create annotated tag
git tag -a v1.1.10 -m "v1.1.10: backup & restore; preserve IDs option; restore improvements"

# Push commit and tag to origin (optional)
# git push origin main
# git push origin v1.1.10

Notes:
- If your branch isn't 'main', replace with the correct branch name when pushing.
- If you want me to run these commands, ensure 'git' is available in the environment or run them locally in PowerShell.
